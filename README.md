## 1. PREREQUISITES

Install the following before starting:

| Tool | Version | Download |
|---|---|---|
| Node.js | v18+ | https://nodejs.org |
| Python | 3.10 – 3.12 | https://python.org |
| MongoDB Atlas | Cloud (already configured) | — |
| Git | Any | https://git-scm.com |

> **IMPORTANT**
> Your `.env` file at `d:\SentinalAI\.env` must contain all required keys before starting.

**Required .env keys:**
```env
MONGO_URI=<your atlas URI>
JWT_SECRET=<your secret>
GROQ_API_KEY=<your groq key>
ABUSEIPDB_API_KEY=<your abuseipdb key>
OTX_API_KEY=<your alienvault otx key>
ML_ENGINE_URL=http://localhost:5001
BACKEND_PORT=5000
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

## 2. PROJECT STRUCTURE

```
d:\SentinalAI\
├── .env                        ← Root environment variables (all services read this)
├── backend\                    ← Node.js / Express API server (Port 5000)
│   ├── controllers\            ← Business logic (alerts, logs, incidents, AI, hunt)
│   ├── models\                 ← MongoDB Mongoose schemas
│   ├── routes\                 ← Express API route definitions
│   ├── services\
│   │   ├── groqService.js      ← Groq AI LLM integration
│   │   ├── threatIntel.js      ← AbuseIPDB + AlienVault OTX
│   │   └── mlService.js        ← Python ML engine client
│   └── server.js               ← Entry point
├── frontend\                   ← Next.js React UI (Port 3000)
│   └── src\app\
│       ├── login\              ← Login page
│       ├── dashboard\          ← Main SOC dashboard
│       ├── alerts\             ← Alert management
│       ├── logs\               ← Log ingestion & viewer
│       ├── incidents\          ← Incident reports
│       ├── rules\              ← Detection rules engine
│       ├── hunting\            ← Threat hunting module
│       └── admin\              ← User management
└── ml-engine\                  ← Python Flask ML microservice (Port 5001)
    ├── train.py                ← Model training script
    ├── app.py                  ← Flask inference API
    ├── requirements.txt        ← Python dependencies
    └── models\                 ← Trained .pkl model files (generated by train.py)
        ├── isolation_forest.pkl
        ├── random_forest.pkl
        └── xgboost.pkl
```

## 6. API TEST REFERENCE

All API endpoints require a JWT token (obtained from login).

### Get JWT Token
```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "your@email.com", "password": "yourpassword"}'
```
**Response:** `{ "token": "eyJ..." }`

Save the token: `TOKEN=eyJ...`

### Key API Endpoints

| Method | URL | Description |
|---|---|---|
| POST | `/api/auth/login` | Login → get JWT |
| POST | `/api/auth/register` | Register new user |
| GET | `/api/logs` | Get all logs |
| POST | `/api/logs/upload` | Upload a log file |
| GET | `/api/alerts` | Get all alerts |
| PATCH | `/api/alerts/:id/status` | Update alert status |
| POST | `/api/ai/analyze/:logId` | Run AI analysis on a log |
| GET | `/api/incidents` | Get all incident reports |
| POST | `/api/incidents` | Create incident report |
| GET | `/api/ai/health` | Check AI service health |
